Security

A plain-language overview of JSONPro's browser-side processing model, safe rendering approach and responsible security contact.

Browser-side processing

The formatter, validator, tree/table viewer, diff, converter, JSONPath helper and JWT decoder execute in the browser. The site does not send the entered JSON or JWT text to a JSON-processing API.

Rendering untrusted input

Values in the tree, table, code and comparison output are rendered as text rather than interpreted as HTML. This is an important defence against script injection through untrusted JSON values. As with any web application, this does not establish that every possible vulnerability is impossible.

Third-party resources

The current application loads Tailwind CSS and Google Fonts from external providers. This means the page is not fully offline and the providers may receive standard network request metadata. See the Privacy Policy.

JWT handling

JWT decoding is for inspection only. The tool does not verify cryptographic signatures and must not be used to make authentication or authorisation decisions.

Report a security issue

Please email support@jsonpro.com with a concise description and safe reproduction steps. Do not include secrets or other people's personal data.
